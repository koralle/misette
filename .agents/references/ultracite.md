# Ultracite Reference

This project uses Ultracite with Oxlint and Oxfmt for automated linting and formatting. Most mechanical issues are automatically fixable.

## Commands

- Fix code: `pnpm fix`
- Check for issues: `pnpm check`
- Diagnose the setup: `pnpm exec ultracite doctor`

Run `pnpm fix` before committing and `pnpm check` before completing code changes.
